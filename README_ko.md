# 🎬 Cinematic Prompt Master（한국어）

**평범한 장면 묘사를 영화급 AI 이미지/비디오 프롬프트로 변환한다 — 목적성 있는 카메라 움직임과 무작위화된 안면 미세 표정과 함께.**

> 다른 언어: [English](README.md) · [简体中文](README_zh-CN.md) · [繁體中文](README_zh-TW.md) · [日本語](README_ja.md) · [Español](README_es.md) · [العربية](README_ar.md)

## 왜 이 skill이 필요한가

대부분의 AI 비디오 프롬프트는 **화면에 무엇이 있는지**만 묘사하고, **카메라가 어떻게 움직이는지**, **그 얼굴이 실제로 무엇을 하고 있는지**는 결코 말하지 않는다.

결과는 매우 뻔하다:

- 📷 카메라가 목적 없이 떠다닌다 — 피사체도, 움직일 이유도 없다
- 😐 매번 클로즈업이 똑같은 「우는／웃는」 정형 표정
- 🔁 열 번 실행하면 열 번 모두 똑같은 얼굴

**Cinematic Prompt Master** 는 이 두 가지를 동시에 해결한다. 모든 프롬프트는 두 관문을 통과한다:

1. **카메라 움직임 검토 및 최적화** — 목적성, 가림 전환, 3축 안정, 리허설감
2. **이중 무작위 안면 주입** — 20 감정 × 3 변형 = 60가지 얼굴 상태를 무작위 추출

---

## 두 가지 코어 규칙

### 1. 카메라 움직임 규칙 (Camera Movement Rules)

| 원칙 | 의미 |
|---|---|
| **목적성 확립** | 카메라는 명확한 피사체를 고정한다. 피사체가 바뀌면 「매끄러운 전환」을 묘사한다. |
| **가림 전환** | 휩팬을 쓰거나, 기둥·행인·몸으로 렌즈를 한순간 가려 컷을 숨긴다. |
| **돌리 + 붐 혼용** | Dolly in / out에 boom / crane을 조합하고, 공간 전환 시 샷 스케일을 바꾼다(와이드 → 클로즈업). |
| **시각적 안정성** | 기본은 3-axis gimbal 또는 slider. 멀미 나는 흔들림은 피한다. |
| **안무된 블로킹** | 카메라, 배우 동선, 조명에 높은 리허설감을 부여해 무결점 롱테이크로 만든다. |

> **예외:** 몽타주(Montage)와 정적 콜라주 — **카메라 움직임 묘사는 전혀 불필요**.

### 2. 이중 무작위 안면 코어 주입

- **1차** — 장면 분위기에서 감정 대분류 1개를 고른다
- **2차** — 그 감정의 **A / B / C** 중에서 **무작위로 하나**를 고른다(매번 같은 것을 쓰는 것은 금지)

### 20가지 감정 카테고리

`분노` · `슬픔` · `공포` · `혐오` · `경멸` · `불안` · `수치심` · `죄책감` · `질투` · `진심으로 기쁨` · `가짜 미소` · `만족` · `감동` · `놀람` · `혼란` · `의심` · `집중` · `억압` · `오만` · `난처함`

각각 해부학적으로 구체적인 3가지 변형(눈썹, 눈꺼풀, 동공, 인중, 팔자주름, 이끌림근……) 총 60가지 상태.

### Claude Code / Claude.ai

```bash
mkdir -p ~/.claude/skills/cinematic-prompt-master
cp SKILL.md ~/.claude/skills/cinematic-prompt-master/SKILL.md
```

`SKILL.md` 의 내용을 프로젝트 규칙 파일(예: `.cursorrules`)이나 system prompt에 붙여넣는다.

`SKILL.md` 를 system instruction으로 붙여넣고, 자연어로 장면을 묘사하면 된다.

## 사용법

```
당신: 해질녘 성벽 위에서 고대 의상의 여인이 누군가를 기다린다.
      해가 져도 그는 오지 않고, 그녀는 돌아서서 떠난다.
```

Skill 은 다음을 포함한 완전한 프롬프트를 반환한다:

- 연속된 카메라 움직임의 사슬(와이드 → 휩팬 → 클로즈업)
- 무작위로 추출된 미세 표정 하나가 프롬프트에 직접 녹아 있음
- 스태빌라이저와 조명 지시

[`examples/before-after.md`](examples/before-after.md) 에 완전한 예시 3개가 있다.

## 잘 쓰는 팁

- 🎲 **3테이크를 요청한다.** 실행마다 다른 A/B/C가 추출되니 가장 좋은 얼굴을 고른다.
- 🗣️ **특정 감정이 있으면 명시한다**; 말하지 않으면 skill 이 분위기에서 고른다.
- 📐 **원하는 샷 스케일을 알려준다**(예: 「마지막은 클로즈업으로 끝내고 싶다」) — skill 이 그곳에 착지하는 카메라 움직임을 설계한다.
- 🎭 **몽타주라면 분명히 말한다** — skill 이 모든 카메라 움직임 언어를 정확히 제거한다.
- 🌏 기본은 영어 프롬프트(대부분의 비디오 모델이 가장 정확히 해석); 필요하면 한국어 출력으로 전환할 수 있다.
