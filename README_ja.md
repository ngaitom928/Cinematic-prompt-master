# 🎬 Cinematic Prompt Master（日本語）

**ありふれたシーンの描写を、映画級の AI 画像・動画プロンプトに変換する —— 目的性のあるカメラワークと、ランダム化された表情の微細な動き付き。**

> 他言語：[English](README.md) · [简体中文](README_zh-CN.md) · [繁體中文](README_zh-TW.md) · [한국어](README_ko.md) · [Español](README_es.md) · [العربية](README_ar.md)

---

## なぜこの skill が必要か

ほとんどの AI 動画プロンプトは**画面に何があるか**だけを描写し、**カメラがどう動くか**、**その顔が実際に何をしているか**を決して語らない。

結果は非常に予測しやすい：

- 📷 カメラが目的なく漂う —— 被写体も、動く理由もない
- 😐 毎回のクローズアップが同じ「泣き／笑い」の定型
- 🔁 10 回実行して、10 回ともまったく同じ顔

**Cinematic Prompt Master** はこの 2 つを同時に解決する。すべてのプロンプトは 2 つの関門を通る：

1. **カメラワークの審査と最適化** —— 目的性、遮断トランジション、3 軸安定、リハーサル感
2. **二重ランダム表情注入** —— 20 感情 × 3 バリアント = 60 種の顔の状態をランダム抽出

---

## 2 つのコアルール

### 1. カメラワークルール（Camera Movement Rules）

| 原則 | 意味 |
|---|---|
| **目的性の確立** | カメラは明確な被写体をロックする。被写体が変わるときは「流暢な引き継ぎ」を描写する。 |
| **遮断トランジション** | ホイップパンを使うか、柱・通行人・体でレンズを一瞬遮ってカットを隠す。 |
| **ドリー＋ブームの混在** | Dolly in / out に boom / crane を組み合わせ、空間転換でショットスケールを変える（ワイド → クローズアップ）。 |
| **安定視覚** | 既定は 3-axis gimbal または slider。眩暈を起こす揺れは避ける。 |
| **振り付けられたブロッキング** | カメラ、役者の動線、照明に高度なリハーサル感を持たせ、ミスのない長回しにする。 |

> **例外：** モンタージュ（Montage）と静止コラージュ —— **カメラワークの描写は完全に不要**。

### 2. 二重ランダム表情コア注入

- **第 1 層** —— シーンの雰囲気から感情の大分類を 1 つ選ぶ
- **第 2 層** —— その感情の **A / B / C** から**ランダムに 1 つ**を選ぶ（毎回同じものを使うのは厳禁）

### 20 の感情カテゴリ

`怒り` · `悲しみ` · `恐怖` · `嫌悪` · `軽蔑` · `不安` · `羞恥` · `罪悪感` · `嫉妬` · `本心からの喜び` · `作り笑い` · `満足` · `感動` · `驚き` · `困惑` · `懐疑` · `集中` · `抑圧` · `傲慢` · `気まずさ`

それぞれに解剖学的に具体的な 3 バリアント（眉、眼瞼、瞳孔、人中、法令紋、オトガイ筋……）、計 60 状態。

## インストール

### Claude Code / Claude.ai

```bash
mkdir -p ~/.claude/skills/cinematic-prompt-master
cp SKILL.md ~/.claude/skills/cinematic-prompt-master/SKILL.md
```

### Cursor / Windsurf / その他のエージェント

`SKILL.md` の内容をプロジェクトのルールファイル（例：`.cursorrules`）や system prompt に貼り付ける。

### その他のモデル（Seedance、Kling、Sora、Runway、Midjourney…）

`SKILL.md` を system instruction として貼り付け、あとは自然言語でシーンを描写するだけ。

## 使い方

```
あなた：夕暮れの城壁で古装の女性が誰かを待っている。
        日が落ちても彼は来ず、彼女は振り返って去っていく。
```

Skill は次を含む完全なプロンプトを返す：

- 連続したカメラワークの連鎖（ワイド → ホイップパン → クローズアップ）
- ランダムに抽選された 1 つの微細な表情が、プロンプトに直接組み込まれている
- スタビライザーと照明の指示

[`examples/before-after.md`](examples/before-after.md) に 3 つの完全な例がある。

## 上手く使うコツ

- 🎲 **3 テイク出してもらう。** 実行ごとに異なる A/B/C が抽選されるので、最良の顔を選ぶ。
- 🗣️ **特定の感情があるなら明示する**；言わなければ skill が雰囲気から選ぶ。
- 📐 **欲しいショットスケールを伝える**（例：「最後はクローズアップで終わりたい」）—— skill がそこに着地するカメラワークを設計する。
- 🎭 **モンタージュなら明言する** —— skill はすべてのカメラワーク言語を正しく削除する。
- 🌏 既定は英語プロンプト（ほとんどの動画モデルが最も精度よく解釈）；必要なら日本語出力に切り替えられる。
