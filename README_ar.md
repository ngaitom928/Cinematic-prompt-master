# 🎬 Cinematic Prompt Master（العربية）

**يحوّل وصف مشهد عادي إلى prompt صور/فيديو بالذكاء الاصطناعي بمستوى سينمائي — مع حركة كاميرا هادفة وتعابير وجه دقيقة مُعشّاة عشوائياً.**

> لغات أخرى: [English](README.md) · [简体中文](README_zh-CN.md) · [繁體中文](README_zh-TW.md) · [日本語](README_ja.md) · [한국어](README_ko.md) · [Español](README_es.md)

## لماذا تحتاج هذا الـ skill

معظم prompts الفيديو بالذكاء الاصطناعي تصف **ما الموجود في الكادر** فقط، لكنها لا تقول أبداً **كيف تتحرك الكاميرا** أو **ماذا يفعل ذلك الوجه فعلياً**.

والنتيجة متوقعة تماماً:

- 📷 الكاميرا تطفو بلا هدف — لا موضوع، ولا سبب لتتحرك
- 😐 كل لقطة قريبة فيها نفس الوجه النمطي «بكاء / ابتسامة»
- 🔁 شغّلها عشر مرات، ستحصل على عشر تعبيرات متطابقة

**Cinematic Prompt Master** يحل المشكلتين معاً. كل prompt يمر ببوابتين:

1. **مراجعة حركة الكاميرا** — هادفة، تستخدم الحجب، مستقرة بثلاثة محاور، بلمسة مُدَرَّبة
2. **الحقن الوجهي مزدوج العشوائية** — 20 عاطفة × 3 متغيرات = 60 حالة وجه تُؤخذ عيّنة منها عشوائياً

## القاعدتان الأساسيتان

### 1. قواعد حركة الكاميرا (Camera Movement Rules)

| المبدأ | المعنى |
|---|---|
| **إرساء الهدفية** | الكاميرا تثبّت موضوعاً واضحاً. إذا تغيّر الموضوع، صف «انتقال اللقطة بسلاسة». |
| **انتقالات الحجب** | استخدم مسحاً سريعاً (whip pan)، أو اجعل عموداً أو مارّة أو جسداً يحجب العدسة للحظة لإخفاء القطع. |
| **مزج Dolly مع Boom** | اجمع dolly in / out مع boom / crane، وغيّر مقياس اللقطة عند تغيّر المكان (لقطة واسعة → لقطة قريبة). |
| **الاستقرار البصري** | كإعداد افتراضي، مثبت ثلاثي المحاور (3-axis gimbal) أو لقطة منزلقة (slider). بلا اهتزاز مسبب للدوار. |
| **حركة مُصمّمة كأنها مُدَرَّبة** | الكاميرا وحركة الممثلين والإضاءة بلمسة تدريب عالية: لقطة متصلة بلا أخطاء. |

> **استثناء:** المونتاج (Montage) والكولاج الساكن — **لا يحتاجان أي وصف لحركة كاميرا**.

### 2. الحقن الوجهي مزدوج العشوائية

- **الطبقة الأولى** — اختر فئة عاطفية واحدة حسب جو المشهد
- **الطبقة الثانية** — اختر **واحداً عشوائياً** من متغيرات **A / B / C** لتلك العاطفة (يُمنع استخدام نفس المتغير كل مرة)

### الفئات العاطفية العشرون

`الغضب` · `الحزن` · `الخوف` · `الاشمئزاز` · `الاحتقار` · `القلق` · `الخجل` · `الشعور بالذنب` · `الغيرة` · `الفرح الحقيقي` · `الابتسامة المزيفة` · `الرضا` · `التأثر` · `المفاجأة` · `الحيرة` · `الشك` · `التركيز` · `الكبت` · `الغطرسة` · `الإحراج`

لكل واحدة 3 متغيرات محددة تشريحياً (الحاجبان، الجفون، الحدقتان، النثرة، الطيات الأنفية الشفوية، العضلة الذقنية…) — 60 حالة في المجموع.

## التثبيت

### Claude Code / Claude.ai

```bash
mkdir -p ~/.claude/skills/cinematic-prompt-master
cp SKILL.md ~/.claude/skills/cinematic-prompt-master/SKILL.md
```

### Cursor / Windsurf / وكلاء آخرون

الصق محتوى `SKILL.md` في ملف قواعد المشروع (مثلاً `.cursorrules`) أو في الـ system prompt.

### أي نموذج آخر (Seedance، Kling، Sora، Runway، Midjourney…)

فقط الصق `SKILL.md` كتعليمات نظام (system instruction)، ثم صف مشهدك بلغة طبيعية.

## نصائح للحصول على أفضل النتائج

- 🎲 **اطلب 3 لقطات (takes).** كل تشغيل يختار متغيراً مختلفاً من A/B/C — اختر أفضل وجه.
- 🗣️ **اذكر العاطفة صراحةً** إن كان لديك واحدة في ذهنك؛ وإلا سيختارها الـ skill من جو المشهد.
- 📐 **سمِّ مقياس اللقطة** الذي تريده (مثلاً «أريد أن تنتهي بلقطة قريبة») وسيصمّم الـ skill الحركة لتصل إلى هناك.
- 🎭 **هل هو مونتاج؟** قل ذلك صراحةً — سيحذف الـ skill كل لغة الكاميرا بشكل صحيح.
- 🌏 الإخراج الافتراضي بالإنجليزية (أفضل ما تُحسّنه معظم نماذج الفيديو). اطلب العربية إذا احتجتها.
